# FanControl 2.5.3

## 连接与设备显示

- 修复 BS1 蓝牙设备断开后重连时错误显示为 WiFi 设备的问题。
- 设备库、设备配置和设置界面保持完整显示；设备是否启用和参与连接由对应兼容模式开关控制。
- WiFi 兼容模式关闭时不再激活或连接 WiFi 设备，重新打开后可继续使用已保存的 WiFi 配置。
- 普通设置、主题和智能控制参数更新不会再打断正在运行的原生 BLE/HID 设备连接。
- 兼容设备切换或连接参数变化时，会先结束旧会话，再应用新的连接配置，避免旧执行器和新设备身份串线。

## 稳定性

- 收紧原生设备重连判断，失效的 BLE 执行器会重新建立实际连接，不再复用陈旧连接状态。
- 断开事件会立即清理设备运行时连接信息，避免继续使用已经失效的转速、能力和控制状态，同时不改变原有设置页布局。
- 保留旧配置中的用户 WiFi 配置内容和设备库展示；兼容模式仅控制设备是否参与实际连接。

## 曲线与历史

- 未连接散热器时，曲线页仅显示风扇与温度历史区域，不加载设备曲线控制区域。
- 只有收到明确的断开状态后才隐藏曲线控制；短暂缺少转速或温度数据不会改变页面显示。
- 离线时不再初始化、归一化或保存风扇曲线，避免打开曲线页后曲线数值被错误压缩或覆盖。
