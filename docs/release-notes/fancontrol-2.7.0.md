# FanControl 2.7.0

## Dock 与导航体验
### Dock and Navigation

- 新增可展开 Dock：紧凑模式保留图标导航，展开后显示完整品牌字标与页面名称。  Added an expandable Dock with compact icon navigation and a full brand wordmark with page labels when expanded.

- 统一 Dock 选中态、悬停效果与页面切换动效，覆盖内置主题和自定义主题。  Unified Dock selection, hover states, and page transitions across built-in and custom themes.

- 改进展开状态下的窗口操作与更新入口。  Improved window actions and update controls while the Dock is expanded.

## 主题与视觉统一
### Themes and Visual Consistency

- 统一窗口幕布、标题栏、Dock 与工作区的衔接方式，减少旧主题中的区域分割感。  Refined the window canvas, title bar, Dock, and workspace so older themes feel continuous.

- 优化深色、浅色和自定义主题的玻璃质感、卡片配色与背景噪点。  Improved glass surfaces, card colors, and background noise across light, dark, and custom themes.

- 改进高级主题在展开 Dock、品牌图标和幕布背景下的兼容性。  Improved advanced-theme compatibility with the expanded Dock, brand marks, and curtain backgrounds.

- 安装升级时更新内置高级主题，同时保留用户主题与已有配置。  Installation upgrades refresh bundled advanced themes while preserving user themes and existing settings.

## 稳定性改进
### Stability Improvements

- 更新前端运行组件，提升安全性与长期兼容性。 Updated frontend runtime components for improved security and long-term compatibility.

- 改进设备连接、重连与恢复后的状态同步。  Improved device state synchronization after connection, reconnection, and resume.

- 提升配置保存、运行时状态更新和页面展示的一致性。  Improved consistency between configuration persistence, runtime state, and the UI.

- 改进曲线编辑与配置切换流程，保留未保存修改。  Improved curve editing and profile switching while preserving unsaved changes.

- 优化更新进度在页面切换后的持续显示。  Improved update progress continuity across page navigation.

## 兼容性说明
### Compatibility Notes

- 可直接覆盖安装旧版本；设备配置、风扇曲线、学习数据、历史记录、主题、托盘设置和 IP 设置将继续保留。  You can install over previous versions. Device settings, fan curves, learning data, history, themes, tray settings, and IP settings are preserved.
